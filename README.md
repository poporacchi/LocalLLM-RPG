# ローカルAI導入診断ウィザード 🗡️

「月1,400円のAPIに、100万円のPCは勝てるか？」という命題に対し、あなたにとって最適なAI環境（クラウドかローカルか）を診断する、ウィザードリィ風・レトロRPGデザインのStreamlitアプリです。

## 🌟 概要
本ツールは、以下の記事のデータをベースに作成されています。
**出典**: [月1,400円のAPIに、100万円のPCは勝てるか？ Sonnet級オープンモデルを自宅で動かす本当のコスト](https://x.com/poporacchi/article/2118836220403040753)

ユーザーはダンジョンを潜るようにいくつかの質問（目的、データの機密性、予算など）に答えることで、
* 推奨されるハードウェア（Mac Studio, RTX 5090等）
* 推定月額維持費（36ヶ月償却＋電気代）
* クラウドAPIを利用した場合との損益分岐（何ヶ月で元が取れるか）
を知ることができます。

## 🚀 遊び方（動かし方）

Python 3.9以上がインストールされた環境で以下を実行してください。

```bash
# 依存ライブラリのインストール
pip install -r requirements.txt

# アプリの起動
streamlit run app.py
```

## 🛠️ あとから改変・修正するには（価格変動への対応）

AIハードウェアの価格、為替レート、電気代などは日々変動します。
本アプリは、そうした変動に簡単に対応できるよう設計されています。

エディタで `app.py` を開き、ファイルの冒頭（10行目付近〜）にある以下の定数を書き換えるだけで、すべての計算・損益分岐が自動的に更新されます。

### 1. 為替や基本コストの変更
```python
EXCHANGE_RATE = 155      # 1ドル＝155円（固定）
PRICE_KWH = 31           # 電気料金 31円/kWh
DEPRECIATE_MONTHS = 36   # 36か月定額償却・残存価値なし
```

### 2. メモリ価格・PCベース価格の変更
```python
# メモリ価格の高騰・下落に合わせて調整
RAM_128GB_NOW = 514_800  

# NVIDIA構築PCのベース代金（GPU・RAM以外のマザボや電源など）
PC_BODY_PRICE = 240_000  
```

### 3. マシンの追加・価格変更
`MACHINES` リスト内の数値を書き換えることで、特定マシンの価格や生成速度（tok/s）を自由に変更できます。
```python
    Machine("Mac Studio M5 Max 128GB", 887_800, False, 128, ...)
    # 887_800 の部分を最新の実売価格に変更するだけ！
```

### 4. クラウドAPI料金の変更
`USAGE` 辞書内の `cloud` の数値を最新の月額（円）に書き換えてください。
